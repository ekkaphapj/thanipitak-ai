# แผนทดลองใช้ธานีพิทักษ์ AI กับข้อมูลจริง

สถานะ: UI และระบบทดลองใช้งานได้ ข้อมูลจริงยังไม่เชื่อมต่อ ตัวเลือกข้อมูลจริงต้องแสดงว่าไม่พร้อม และ backend ปฏิเสธคำขอแหล่งข้อมูลที่ยังไม่รองรับ ห้ามส่งข้อมูลทดสอบกลับโดยติดป้ายว่าเป็นข้อมูลจริง

## รูปแบบนำร่อง

ให้ผู้ใช้เปิดเว็บผ่าน HTTPS บนเซิร์ฟเวอร์กลางที่เข้าถึง Ollama ในเครือข่ายภายใน ผู้ใช้มือถือไม่ต้องติดตั้ง Ollama เริ่มจากผู้ใช้กลุ่มเล็กหนึ่งสถานี แล้วเพิ่มสถานีเมื่อทดสอบสิทธิ์ข้ามพื้นที่ผ่าน

## สองแหล่งข้อมูล

- ทดสอบ: SQLite และบัญชีจำลอง แสดงแถบข้อมูลทดสอบตลอดการสนทนา
- จริง: Supabase และการเข้าสู่ระบบของธานีพิทักษ์ ตรวจตัวตนและสิทธิ์สถานีที่ backend ทุกครั้ง ใช้สิทธิ์อ่านเท่านั้นกับตารางต้นทาง และคงการจำกัดแถวตามผู้ใช้ ห้ามนำ token ของบัญชีทดลองไปใช้กับข้อมูลจริง
- การสลับ: ยกเลิกคำขอค้าง ล้างแชต บุคคลที่เลือก ตัวเลือกค้นหา รายงานที่รอสร้าง และลิงก์ดาวน์โหลดก่อนเริ่ม session ของอีกแหล่งข้อมูล รายงานต้องระบุแหล่งข้อมูลและเวลาที่ดึงข้อมูล

## งานเชื่อมต่อที่ต้องทำก่อนเปิดข้อมูลจริง

1. ตรวจ schema และสิทธิ์ Supabase จากสำเนาสำหรับทดสอบ สร้าง data adapter สำหรับทะเบียนบุคคล ผลเยี่ยม สถานะรายงานผู้ดูแล พื้นที่ และประเภทบุคคล
2. ใช้สถานะ/เกณฑ์ที่ระบบจริงรับรอง คำนวณประกอบคำตอบในหน่วยความจำ ไม่เขียนสถานะกลับ การอ่าน AI ใน sandbox ได้ถอด UPDATE สถานะรายงานออกแล้ว
3. แยก audit และ feedback ไว้ฐานข้อมูลของ AI ปิดเส้นทาง simulation/admin ที่แก้ทะเบียนในการติดตั้งนำร่อง บัญชีฐานข้อมูลจริงต้องไม่สามารถ INSERT/UPDATE/DELETE ได้ แม้ endpoint ถูกเรียกโดยตรง
4. ตรวจยอดและรายชื่อเทียบระบบหลัก ทดสอบการเลือกบุคคล ข้ามสถานี เปลี่ยนแหล่งข้อมูลกลางคำขอ และรายงาน PDF ทดสอบจำนวนข้อมูลมากกว่าหน้าแรกด้วย
5. เปิดให้ผู้ใช้กลุ่มทดลอง เก็บปัญหาพร้อมรหัสคำตอบ เวลา แหล่งข้อมูล ประเภทปัญหา และข้อความที่ผู้ใช้ยินยอมส่ง ไม่เก็บ prompt/ข้อมูลบุคคลทุกคำถามอัตโนมัติ

## เกณฑ์ก่อนเผยแพร่

ต้องผ่านการพิสูจน์ว่าอ่านข้อมูลจริงแล้วไม่มีการเขียนต้นทาง, สิทธิ์ข้ามสถานีไม่รั่ว, PDF ตรงกับข้อมูลและเงื่อนไข, ปิดการใช้รหัสผ่านจำลองกับระบบจริง, จำกัดผู้เข้าทดลอง และมีช่องทางรับแจ้งปัญหา การอ่านอย่างเดียวช่วยป้องกันข้อมูลถูกแก้ แต่ยังต้องควบคุมการเข้าถึงและการดาวน์โหลด

ยังไม่มีการเผยแพร่เว็บหรือย้ายข้อมูลจริงในขั้นตอนออกแบบนี้
