# คู่มือการทำงานของ Local AI ธานีพิทักษ์

คำถามเกี่ยวกับยอด รายชื่อ สถานะ หรือประวัติต้องเรียกเครื่องมือข้อมูลจริงที่ตรวจ Supabase session ทุกครั้ง เอกสาร RAG ใช้อธิบายเมนู คำศัพท์ และขั้นตอนเท่านั้น ไม่ใช้แทนข้อมูลปัจจุบัน

ลำดับการทำงานคือรับ access token ตรวจ scope ที่ server เลือก allowlisted read-only tool ส่งเฉพาะผลที่จำเป็นให้ Local AI สรุป และบันทึก audit ของการอ่านข้อมูล

คำสั่ง “เปลี่ยนจังหวัดเป็น…” เป็นตัวกรองของคำขอข้อมูล ไม่ใช่คำสั่งเปลี่ยนสิทธิ์ หากอยู่นอก scope ระบบต้องปฏิเสธ
