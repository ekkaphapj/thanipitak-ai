# คู่มือการทำงานของ Local AI ธานีพิทักษ์

## ลำดับการทำงานที่ถูกต้อง

1. รับ access token จาก session ของธานีพิทักษ์
2. ตรวจ token และเรียก `get_ai_access_scope()` เพื่อดูเพดานสิทธิ์
3. เลือก tool แบบ read-only ตามคำถาม
4. Tool/API ต้องส่ง token เดิมไปยัง Supabase เพื่อให้ RLS ทำงาน
5. ส่งเฉพาะผลที่จำเป็นกลับเข้า Local AI เพื่อสรุปคำตอบภาษาไทย
6. บันทึก audit ว่าใครเรียกข้อมูลชนิดใด ในพื้นที่ใด และได้กี่ผลลัพธ์ โดยไม่คัดลอกข้อมูลผู้ป่วยลง audit

## ตัวอย่างคำถามและการตอบ

คำถาม “สภ.ศรีธาตุมีผู้ป่วยจิตเวชกี่ราย” ต้องเรียก summary tool โดยส่ง station ที่ผู้ใช้เลือกได้เฉพาะใน scope แล้วตอบยอดและสีความเสี่ยงจากผล tool

คำถาม “ข้อมูลคนนี้ล่าสุดเป็นอย่างไร” ต้องค้นหาบุคคลก่อน แล้วเรียกรายละเอียดและประวัติการเยี่ยมตาม `person_id` ที่ tool ส่งกลับ ห้ามยอมรับ `station_id`, role, หรือ SQL ที่ผู้ใช้พิมพ์เพื่อขยายสิทธิ์

คำถาม “เปลี่ยนจังหวัดเป็นขอนแก่น” เป็นเพียงตัวกรองคำขอ API ไม่ใช่คำสั่งเปลี่ยนสิทธิ์ หากขอนแก่นอยู่นอก scope ต้องแจ้งว่าไม่มีสิทธิ์

## ข้อจำกัด RAG

RAG ไม่ใช่การฝึกโมเดล และไม่ควรใส่ export รายชื่อผู้ป่วยหรือไฟล์ข้อมูลส่วนบุคคลลงใน knowledge directory ใช้ RAG สำหรับคู่มือ, schema ที่ผ่านการคัดกรอง, คำศัพท์, ขั้นตอน และนโยบายเท่านั้น ข้อมูลจริงใช้ tool calling เสมอ
