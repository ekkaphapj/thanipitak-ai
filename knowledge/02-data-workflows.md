# ข้อมูลและขั้นตอนปฏิบัติงาน

ทะเบียนบุคคลเชื่อมสังกัดและประเภทบุคคล กลุ่มหลักได้แก่ผู้ป่วยจิตเวช ผู้เสพ ผู้ค้า และผู้พ้นโทษ สถานะสีของผู้ป่วยจิตเวชเป็นข้อมูลที่ต้องตอบจากทะเบียนจริงเท่านั้น

การตรวจเยี่ยมและงานคดีเป็นข้อมูลที่ต้องเรียกผ่านเครื่องมือที่ได้รับอนุญาต ผู้ช่วย AI มีหน้าที่อ่านและสรุปผล ไม่สร้าง แก้ไข หรือลบข้อมูล และไม่สรุปเชิงกฎหมายหรือวินิจฉัยเกินข้อมูลที่บันทึกไว้

ห้ามใส่ PIN, credential, API key, service-role key หรือ export รายชื่อบุคคลใน RAG
